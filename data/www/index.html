Remote logging

Send a copy of the System Log to other servers, to keep the history beyond the buffer of the board. Settings are saved on the device and applied without a restart.

Syslog

Lines are sent over UDP by a background task: they never delay the UPS or the NUT server. With the time synchronized () each line carries the time it was written and, in RFC 3164, the host name of the Network page; without it the server timestamps each line when it arrives and RFC 3164 lines carry no host name. RFC 5424 lines always carry the host name.

UDP syslog is not encrypted: anyone on the LAN can read the lines, including the usernames of failed logins.
