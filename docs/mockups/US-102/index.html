ESP32-NUT INSTALLER

Firmware Installation

  1. Connect your ESP32 board to the computer via USB cable.
  2. Make sure to use a data cable (not just for charging).
  3. Click the button below and select the serial port corresponding to your device.

ESP32-P4 (Ethernet)

The button above is for ESP32-S3 boards. For an ESP32-P4 board, pick the image that matches your chip revision.

How do I know my P4 revision?

Use one of these:

  • Run esptool chip-id (or esptool.py chip_id) and look for: 
    Chip is ESP32-P4 (revision v1.3)
  • Open the serial monitor, reset the board and look in the boot log for: 
    chip revision: v1.3
v1.x→ ESP32-P4 before v3
v3.1+→ ESP32-P4 v3.1 or later
v2.x, v3.0Not supported by either image

Picked the wrong one? No harm done: the bootloader refuses the image. Just flash again with the other button.

Supported boards: Waveshare ESP32-P4-ETH (also PoE) and boards following the Espressif reference design (IP101 PHY).

Supported browsers: Chrome, Edge, Opera.

Requirements: Web Serial API enabled.
