Remote logging

Send a copy of the System Log to other servers, to keep the history beyond the buffer of the board. Settings are saved on the device and applied without a restart.

Syslog

Lines are sent over UDP by a background task: they never delay the UPS or the NUT server. The board has no clock, so the server timestamps each line when it arrives.

UDP syslog is not encrypted: anyone on the LAN can read the lines, including the usernames of failed logins.
