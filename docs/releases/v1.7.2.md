Bug-fix release for APC owners. `ups.model` now shows the model name only, as NUT does, and the firmware versions get their own variables.

## ⚠️ Upgrade notes

- **APC: shorter `ups.model` and `device.model`** ([#76](https://github.com/maverick1982/esp32-nut/issues/76)). The firmware part of the USB product string now goes to `ups.firmware` and `ups.firmware.aux`, as upstream `usbhid-ups` does. For example, `Back-UPS ES 700G FW:871.O4 .I U` becomes `ups.model = Back-UPS ES 700G`, `ups.firmware = 871.O4 .I` and `ups.firmware.aux = O4`. If you have automations or dashboards that match the full model string, update them.

## New and improved UPS support

- **APC Back-UPS ES 700G** (`051D:0002`): tested on real hardware, now listed in the README. ([#71](https://github.com/maverick1982/esp32-nut/issues/71))
- **APC Back-UPS BX750MI, BX1200MI** (`051D:0002`): added to the tested models in the README, with a note on the USB lockups of the BX firmware that v1.7.1 recovers from. ([#60](https://github.com/maverick1982/esp32-nut/issues/60))

## Fixes

- **APC:** `ups.model` was the raw USB product string cut at 31 characters, firmware included (`Back-UPS ES 700G FW:871.O4 .I U`). It now holds the model only, and `ups.firmware` / `ups.firmware.aux` are published. ([#76](https://github.com/maverick1982/esp32-nut/issues/76))
- **All brands:** manufacturer, model and serial strings longer than 31 characters are no longer cut. Up to 63 characters are read. ([#76](https://github.com/maverick1982/esp32-nut/issues/76))

## Thanks

- @miskor-bgd for testing a Back-UPS ES 700G and sending the USB diagnostics that revealed the truncated model (#71).

## Install

Flash it from the [web installer](https://maverick1982.github.io/esp32-nut/) or upload `firmware.bin` from the attached zip through OTA in the web UI. Coming from v1.5.x or earlier, use the web installer (see the [v1.6.0 notes](https://github.com/maverick1982/esp32-nut/releases/tag/v1.6.0)).
