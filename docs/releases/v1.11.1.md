Maintenance release: on Eaton UPSes every value, the status and the commands now come from the same table that the NUT usbhid-ups driver uses (mge-hid), so they match what NUT on a PC would show. Nothing changes for the other brands.

## ⚠️ Upgrade notes

- **Eaton: variables now named and computed as in NUT.** Check your Home Assistant sensors and scripts:
  - `outlet.1.switch` and `outlet.2.switch` are replaced by `outlet.N.status` (`on`/`off`), one per outlet group: the old keys repeated the same value for both;
  - `input.voltage.nominal` and `input.frequency.nominal` are published only by models that report the input nominal values (NUT reads them from a different place than the output ones). On an Eaton 3S they disappear: the old values were the output ones, still available as `output.voltage.nominal` and `output.frequency.nominal`;
  - `ups.realpower`, on models that do not measure it, is estimated as NUT does, with a power factor of 0.8 (or `output.powerfactor`) instead of 0.6: on an Eaton 3S at 5 % load it goes from 21 W to 28 W;
  - new variables, as published by usbhid-ups: `ups.type` (the topology, which the firmware meant to publish but never found), `ups.timer.start`, `ups.firmware`, `device.usb.version`, `outlet.id`, `outlet.switchable`, `outlet.1.id`, `outlet.1.switchable`, `outlet.1.protect.status`, and on larger models `ups.efficiency`, `output.current`, `output.powerfactor` and the bypass values.

  Commands and writable settings of the Eaton 3S are the same as v1.11.0.
- **Eaton: `shutdown.return` and `shutdown.stayoff` set `ups.start.auto`** (to `yes` and `no`) before the shutdown, as NUT does, on models that have this setting. It is a setting stored in the UPS.
- **Eaton 5P, 9E and similar series:**
  - `battery.capacity` is in Ah with two decimals, as in NUT;
  - `battery.capacity.full` is no longer published (it is not a standard NUT name);
  - `battery.voltage` and `battery.voltage.nominal` are published only for the series NUT reads them for;
  - with Advanced Battery Monitoring enabled, `battery.charger.status` and `battery.charger.type` appear, and `ups.status` shows `RB` when the UPS reports a missing battery.

  Checked on the recorded data of an Eaton 5P, not on the hardware: if your Eaton behaves differently after the update, please open an issue and attach the USB diagnostics export.

## Other changes

- **Eaton driver:** values, status flags and instant commands are rows of the mge-hid table, copied from NUT line by line, instead of hand-written mappings. The firmware writes a value only when it changes, which saves memory allocations at every USB report.
