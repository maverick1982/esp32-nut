Maintenance release: on Eaton UPSes the battery values and the status now come from the same table that the NUT usbhid-ups driver uses (mge-hid), so they match what NUT on a PC would show. Nothing changes for the other brands.

## ⚠️ Upgrade notes

- **Eaton: a few new variables.** NUT clients may see `ups.timer.start`, `ups.firmware` and `device.usb.version`, which usbhid-ups also publishes. On an Eaton 3S nothing else changes: same variables, values, commands and writable settings as v1.11.0.
- **Eaton 5P, 9E and similar series:**
  - `battery.capacity` is in Ah with two decimals, as in NUT;
  - `battery.capacity.full` is no longer published (it is not a standard NUT name);
  - `battery.voltage` and `battery.voltage.nominal` are published only for the series NUT reads them for;
  - with Advanced Battery Monitoring enabled, `battery.charger.status` and `battery.charger.type` appear, and `ups.status` shows `RB` when the UPS reports a missing battery.

  Checked on the recorded data of an Eaton 5P, not on the hardware: if your Eaton behaves differently after the update, please open an issue and attach the USB diagnostics export.

## Other changes

- **Eaton driver:** the PowerSummary and BatterySystem values and the status flags are rows of the mge-hid table, copied from NUT line by line, instead of hand-written mappings. The firmware writes a value only when it changes, which saves memory allocations at every USB report.
