ESP32-P4 release: esp32-nut now runs on ESP32-P4 boards with a wired Ethernet port, such as the Waveshare ESP32-P4-ETH, as well as on the ESP32-S3. Nothing changes for ESP32-S3 users: same image, same installer button, same zip name.

## ⚠️ Upgrade notes

- **Internal rework of the UPS drivers.** The NUT server, the web UI and the UPS drivers no longer depend directly on the USB code. NUT clients should see the same variables, commands and writable settings as with v1.10.0: this was checked on an Eaton 3S, and on the other brands with the recorded data of their UPS. If your UPS behaves differently after the update, please open an issue and attach the USB diagnostics export.

## ESP32-P4 with Ethernet (experimental)

- **Boards:** Waveshare ESP32-P4-ETH (also the PoE version) and boards that follow the Espressif reference design (IP101 PHY). The UPS goes on the USB 2.0 High-Speed port. The board joins the network by cable with DHCP, as `esp32-nut-xxxxxx`; there is no Wi-Fi and no access point, and a double reset opens a 10-minute window to replace the web credentials (#94, #103).
- **Two images, one per chip revision.** Pick the one that matches your chip: `esptool chip-id` shows it (`Chip is ESP32-P4 (revision v1.3)`), and so does the boot log (`chip revision: v1.3`).

| Image | Chip revision | Tested on |
| :--- | :--- | :--- |
| ESP32-P4 v3.1 or later | v3.1 and later | **Not yet tested on hardware** |
| ESP32-P4 before v3 | v1.x | A v1.3 board with a UPS (rtadams89) |

- An image for the wrong chip or revision is refused, by the bootloader on a full install and by the board on an OTA update: the board keeps the firmware it is running. If you try the v3.1+ image, please tell us how it went.

## Other changes

- **Web installer:** the main button still installs the ESP32-S3 image; a new ESP32-P4 section has one button per chip revision and explains how to read the revision.
- **Release packages:** one zip per board. The ESP32-S3 zip keeps its name (`esp32-nut-v1.11.0.zip`); the P4 zips end with `-esp32-p4-eth` and `-esp32-p4-eth-v1`. Every zip now also has `firmware.factory.bin`, the complete image to write at `0x0`, and a `README.txt` with the install steps.
- **UPS Compatibility Report:** a new issue form to tell us that your UPS works, linked from the README (#83).

## Install

Flash it from the [web installer](https://maverick1982.github.io/esp32-nut/) or upload `firmware.bin` (or the whole zip of your board) through OTA in the web UI.
